In the terminal

kovan is Kovan's coding agent on its own, for macOS, Linux and Windows. It needs Node.js 22 or newer, installs for you alone (no admin rights), checks the download's signature and keeps itself up to date.

macOS and Linux

curl -fsSL https://kovan.alperkayan.dev/install.sh | sh

Windows (PowerShell)

irm https://kovan.alperkayan.dev/install.ps1 | iex

Then run kovan in a project folder. How it works
