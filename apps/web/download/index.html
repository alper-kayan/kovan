Get Kovan for your desktop.

One desktop app for macOS, Windows and Linux. Free during early access; you pay only for the AI models your agents use (how).

What you need

  • A project in Git, cloned on this computer (Kovan opens any folder; Git is what lets teammates share the work). Joining a team? Ask for access to its repository on GitHub or GitLab first.
  • An AI model or account: your Claude Code or Codex sign-in, an OpenRouter key, or paying through Kovan. The app helps you pick when you start.
  • An account only to work with others or use the phone app. Alone, you can skip it.

In the terminal

Prefer the terminal, or on an Intel Mac? kovan is Kovan's coding agent without the app: you talk to it in a terminal, like Claude Code, and its chats show up in the desktop app too. It needs Node.js 22 or newer, installs for you alone (no admin rights), checks the download's signature and keeps itself up to date.

macOS and Linux

curl -fsSL https://kovan.alperkayan.dev/install.sh | sh

Windows (PowerShell)

irm https://kovan.alperkayan.dev/install.ps1 | iex

Then run kovan in a project folder. How it works

On your phone

The Kovan phone app follows your team's work: what each agent is doing, a yes when one asks for it, and work started on your computer. The agents themselves run on a computer, so install Kovan there too.

The app is on its way to the App Store and Google Play.

On a phone? The agents run on a computer: open this page on a Mac, a Windows PC or a Linux machine to install Kovan there. For the phone itself, see On your phone.
