# Start here

Kovan is a code editor where you and your teammates each work with an AI agent, and everyone sees what every agent is doing as it happens. These docs are in the order most people need them; pick the path that fits you.

## I want to try it on my own

1. [Getting started](/docs/getting-started/): install the app, open a project folder, get an agent ready.
2. [Agents](/docs/agents-and-harnesses/): Kovan's own agent, or your Claude Code or Codex.
3. [AI models and JevRouter](/docs/models-and-jevrouter/): which model, and what it costs.

You don't need an account for this. Kovan is free during early access; you pay only for the AI your agents use, with your own key or subscription, or through Kovan.

## Someone invited me to their team

1. Open the invite link from the email (or the one your teammate sent you) and sign in with that address.
2. Make sure you can open the team's repository on GitHub or GitLab: Kovan works on your own copy of it, so you need access. Ask whoever invited you.
3. [Getting started → Joining a team](/docs/getting-started/#joining-a-team), then [Working together in a session](/docs/sessions-and-lanes/).

Only want to follow along and approve things? The [phone app](/docs/phone-app/) is enough, and in the desktop app you can watch without a copy of the code.

## I run the team

1. [Workspaces and who can do what](/docs/workspaces-and-roles/): share a project, invite people, pick their roles.
2. [Paying for AI](/docs/managed-usage-and-billing/): each person pays their own way, or the team pays for everyone.
3. [Security and privacy](/docs/security-and-privacy/): what Kovan's server keeps, and for how long.

## I live in the terminal

[The terminal agent](/docs/terminal-agent/) is Kovan's agent without the app: `kovan` in any project folder. Its chats show up in the desktop app too.

## Words you'll meet

The [glossary](/docs/glossary/) explains session, lane, swarm, JevRouter and the rest in a line each.
